## Abstract

This survey reviews 47 research papers (2021–2026) on deep learning applied to panoramic dental radiograph analysis. Coverage includes caries detection, severity staging, periodontal bone loss assessment, multi-task OPG diagnosis, explainable AI, and tooth segmentation.

## Key Findings

- Best caries models: >98% AUC
- Best bone loss detection: 99.5% mAP50
- Explainability implementation rate: **6.4%** (critically low)
- No unified multi-disease pipeline exists in literature

## Five Critical Gaps

1. Single-disease model focus
2. Absence of automated severity staging
3. 6.4% explainability rate
4. Dataset fragmentation (single-center)
5. Poor clinical workflow integration
