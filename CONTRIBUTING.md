# Contributing

Thank you for your interest in improving this repository.

## Scope

Contributions are welcome for:
- Documentation improvements
- Repository organization and metadata
- Reference list cleanup and consistency
- Manuscript source quality (LaTeX clarity, citation consistency)

## How To Contribute

1. Fork the repository.
2. Create a topic branch.
3. Make focused changes with clear commit messages.
4. Open a pull request that explains:
   - what changed
   - why it changed
   - any impacts on manuscript build or references

## Pull Request Guidelines

- Keep changes scoped and reviewable.
- Do not include unrelated formatting-only changes.
- Preserve original scientific meaning when editing text.
- Verify LaTeX still builds if you edit manuscript files.

## File Handling Rules

- Do not commit private datasets or patient data.
- Do not upload copyrighted papers unless you have legal rights.
- For third-party PDFs, prefer citation metadata and links where possible.

## Code of Conduct

Be respectful and constructive in all discussions and reviews.
